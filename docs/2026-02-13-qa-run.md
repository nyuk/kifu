## 2026-02-27 Local QA Execution Log

### Scope
- Objective: verify "home reflects today trade" flow end-to-end with automated checks.
- Command used:
  - `bash scripts/full-qa.sh http://127.0.0.1:8080 http://127.0.0.1:3001`

### Issues observed
1. Playwright runtime/install issues on server environment:
- Node runtime mismatch and missing browser binaries.
- `globalSetup` parser compatibility error.

2. Test flakiness in UI smoke:
- Premature API request context disposal caused import call failure.
- Response wait timing issue (`waitForResponse` attached too late).
- Brittle assertion based on transient UI text/placement.

3. Local execution environment issues:
- Docker daemon not running (`Cannot connect to Docker daemon`).
- DB unavailable (`127.0.0.1:5432 connection refused`) causing API smoke 500s.
- CORS block when frontend used `http://127.0.0.1:3001`.

### Fixes applied
- Test stability:
  - Kept `APIRequestContext` alive until test end.
  - Added API-level consistency wait for `/api/v1/trades/summary` (`total_trades > 0` and expected symbol present).
  - Changed response wait sequence to register before `page.goto('/home')`.
  - Reduced dependence on volatile Korean UI text for pass/fail.

- Compatibility:
  - `playwright.config.ts` now uses `globalSetup: './tests/global-setup.ts'`.

- Backend local CORS defaults:
  - Included `localhost/127.0.0.1` for ports `5173`, `3001`, `3000`.

### Final result
- `scripts/full-qa.sh` completed green.
- UI smoke result:
  - `kifu core routes smoke`: PASS
  - `home reflects today trade after user-like import flow`: PASS
