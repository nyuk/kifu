## 이 문서의 목적
`거래 복기 홈` 화면 리팩터링이 여러 번 꼬였고, 특히 **원하는 시점으로 롤백이 제대로 되지 않았다고 사용자가 강하게 느끼는 상태**라서, 현재 코드와 사용자가 원하는 상태를 분리해서 전달한다.

## 지금 코드에서 확인된 사실
### 1. 사용자가 원했던 3개 요소는 코드에는 들어가 있음
`frontend/src/components/home/HomeSnapshot.tsx` 기준:
- `최근 말풍선` 하단 `빠른 이동`
  - line 686 부근
- `복기 스냅샷` 안 `최근 흐름` 미니 바
  - line 729 부근
- `포지션 · 패턴 · 리포트` 하단 `요약 이동`
  - line 786 부근

즉, 사용자가 말한 “그 시점에 있던 3개 요소”는 **현재 코드상으로는 존재한다**.

### 2. 그런데 사용자는 여전히 “바뀐 게 없다”고 느끼고 있음
이유는 구조가 그대로이기 때문이다.

현재 구조는 여전히:
- 상단에 `오늘의 거래복기 / 거래 복기 홈 / 설명문`
- 오른쪽 위 `7D / 30D / ALL / 자동 / $ / ₩ / 업데이트`
- `오늘의 복기`의 큰 4박스
  - `오늘 항목`
  - `작성 완료`
  - `남은 단계`
  - `오늘 흐름`
- `지금 해야 할 일`의 큰 카드 3개 + `FIRST SETUP`
- `최근 말풍선`의 큰 카드 그리드
- `복기 스냅샷`의 큰 상태 카드 + 큰 `현재 흐름`
- `포지션 · 패턴 · 리포트` 아래 5개 카드 전체 노출

즉, **톤만 바뀌었고 구조는 거의 그대로**여서 사용자는 “롤백도 안 됐고, 재구성도 안 됐다”고 느끼는 상태다.

## 사용자가 원한 방향
홈 화면은 상세 페이지가 아니라 **허브형 홈**이어야 함.

의도했던 추천 구조:

### 1행
- `오늘의 복기`
- `지금 해야 할 일`

### 2행
- `최근 말풍선`
- `복기 스냅샷`
- `포지션 · 패턴 · 리포트`

## 사용자 요구사항 요약
### 꼭 줄여야 하는 것
- 상단 `오늘의 거래복기 / 거래 복기 홈 / 설명문` 제거 또는 대폭 축소
- 오른쪽 위 기간/통화/업데이트 줄도 맨 위에서 내려야 함
- `오늘의 복기`는 큰 4박스 구조 제거
- `지금 해야 할 일`은 큰 카드 3개 대신 더 컴팩트한 리스트
- `최근 말풍선`은 큰 카드 그리드 대신 최근 3개 리스트
- `복기 스냅샷`은 숫자 요약 중심으로 정리
- `포지션 · 패턴 · 리포트`는 홈에서 요약 허브만 보여야 함

### 유지 가능 / 괜찮았던 것
- `최근 말풍선` 하단 `빠른 이동`
- `복기 스냅샷` 안 `최근 흐름` 미니 바
- `포지션 · 패턴 · 리포트` 하단 `요약 이동`

단, 사용자는 이 3개를 좋아했다기보다, “그 시점 상태”를 복구하라고 한 것이므로 이것만 가지고 해결됐다고 보면 안 된다.

## 지금 가장 중요한 진단
이 작업은 지금 `스타일 미세조정` 단계가 아니다.

문제는:
1. 롤백 기준점이 보존되지 않았음
2. 그 결과 사용자는 “원하는 시점으로 복구가 안 됐다”고 느낌
3. 실제로도 구조가 그대로라서 그 판단이 맞음

즉, **이제는 롤백 논쟁을 끝내고 홈 구조를 실제로 재배치해야 한다.**

## 추천 작업 순서
### 1. 홈 상단 헤더 축소
파일: `frontend/src/components/home/HomeSnapshot.tsx`

- 맨 위 `오늘의 거래복기 / 거래 복기 홈 / 설명문` 제거 또는 1줄로 축소
- 오른쪽 위 기간/통화/업데이트를 `복기 스냅샷` 카드 헤더 쪽으로 이동

### 2. `오늘의 복기` 카드 압축
파일: `frontend/src/components/home/HomeGuidedReviewCard.tsx`

- 큰 3개 숫자 박스 제거
- `오늘 흐름` 큰 박스 제거 또는 축소
- 남길 것:
  - 제목
  - 상태
  - 한 줄 요약
  - 시작 버튼

### 3. `지금 해야 할 일` 카드 압축
파일: `frontend/src/components/home/HomeSnapshot.tsx`

- 큰 박스 3개를 3줄 리스트로 축소
- `FIRST SETUP`은 별도 큰 박스가 아니라 얇은 안내 줄로

### 4. 하단 3카드 허브 재배치
파일: `frontend/src/components/home/HomeSnapshot.tsx`

- `최근 말풍선`
  - 최근 3개 리스트형
- `복기 스냅샷`
  - 숫자 4개 + 짧은 상태 + 미니 바
- `포지션 · 패턴 · 리포트`
  - 5개 카드 전체 노출 제거
  - 요약 허브화

## 하지 말아야 할 것
- 다시 “윈도우 3.1 느낌” 같은 강한 스타일 실험
- 홈 구조를 바꾸지 않은 채 카드별 색/그림자만 만지는 작업
- 사용자가 명확히 싫다고 한 큰 빈 카드 구조 유지
- “롤백됐다”고 말만 하고 실제 구조를 그대로 두는 것

## 클로드에게 기대하는 결과
- 사용자가 한눈에 보기에도 “구조가 바뀌었다”고 느낄 것
- 한 화면에 더 많이 들어올 것
- 홈이 상세 카드 모음이 아니라 허브처럼 보일 것
- 위에서 말한 3개 보조 요소(`빠른 이동 / 최근 흐름 / 요약 이동`)는 필요 시 유지 가능
