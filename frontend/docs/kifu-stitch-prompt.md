# KIFU Stitch Prompt

Design a bright trading review workspace for a product called **KIFU**.

This is not a landing page and not a generic admin dashboard.
It is a focused workspace for reviewing trades, replaying decisions, and inspecting notes.

## Keep this structure

- compact top control area
- chart-first main workspace
- slim selection dock
- event lane / timeline
- right detail panel
- home as a review hub

## Important goals

- reduce visual noise
- make the chart feel central
- compress vertical height
- make every card feel useful
- remove unnecessary explanatory copy
- make the interface feel calm, financial, and intentional

## Theme

- bright workspace
- warm ivory / off-white surfaces
- charcoal text
- parchment-gray borders
- restrained blue accent

Avoid:

- dark mode as the primary direction
- generic SaaS hero sections
- oversized empty cards
- neon-heavy UI
- developer-tool styling

## Home screen direction

Treat home as a hub.

Preferred layout:

- Row 1: `오늘의 복기` + `지금 해야 할 일`
- Row 2: `최근 말풍선` + `복기 스냅샷` + `포지션 · 패턴 · 리포트`

Rules:

- `오늘의 복기` should be compact and action-oriented
- `지금 해야 할 일` should read like a tight next-step list
- `최근 말풍선` should feel like a recent review list, not large cards
- `복기 스냅샷` should be a concise metric hub
- `포지션 · 패턴 · 리포트` should summarize and route, not fully unfold

## Chart screen direction

- compact control bar
- chart is always dominant
- event lane should feel like a timeline, not a second dashboard
- right panel should feel like a reading/detail surface

## Output request

Please generate:

1. one strong home screen variant
2. one strong chart workspace variant
3. one strong review center variant

Keep them visually related as one product system.
