# Kifu Landing Core Message

기준 날짜: 2026-04-12  
레인: `Kifu Marketing`

## 목적

이 문서는 현재 Kifu 랜딩 메시지를
제품 개발 스레드와 분리된 마케팅 관점에서 먼저 고정하기 위한 초안이다.

지금 단계에서는 화면 구조나 디자인보다
무엇을 먼저 말해야 하는지에 집중한다.

## 한 문장 정의

Kifu는 트레이더가 지나간 거래를 차트만이 아니라 판단 이유까지 다시 꺼내볼 수 있게 만드는 기록형 복기 도구다.

## 핵심 문제

트레이더는 예전 차트는 기억해도
왜 진입했고 왜 청산했는지는 생각보다 빨리 잊는다.

그래서 비슷한 장이 다시 와도
과거의 내 판단이 아니라 현재 감정으로 다시 반응하게 된다.

## 핵심 약속

Kifu는 거래 결과만 남기는 도구가 아니라
그날의 진입 이유, 정리 이유, 복기 메모를 함께 남겨
나중에 다시 확인할 수 있게 만드는 도구다.

## 랜딩 메시지 우선순위

1. 차트보다 먼저 사라지는 것은 판단 이유다.
2. 기록이 없으면 복기는 기억 보정이 된다.
3. Kifu는 거래를 다시 보는 것이 아니라 판단을 다시 꺼내보게 한다.

## Hero 초안

### 헤드라인 후보

- 차트는 남아도 판단 이유는 남지 않습니다
- 지나간 거래를 결과가 아니라 이유까지 다시 보세요
- 같은 장이 다시 와도 내 기준부터 꺼내볼 수 있게

### 서브카피 후보

- Kifu는 트레이더가 왜 진입했고 왜 정리했는지, 그날 어떤 기준으로 판단했는지를 거래 기록과 복기 메모로 함께 남기게 돕습니다.
- 지나간 거래를 차트 캡처로만 남기지 말고, 진입 이유와 정리 이유까지 기록해 두세요. 비슷한 장이 다시 왔을 때 가장 먼저 필요한 건 결국 내 판단의 흔적입니다.

### CTA 후보

- 내 최근 거래 다시 보기
- 판단 이유 남기기
- 복기 흐름 보기

## 메시지 블록

### 블록 1

제목: 차트보다 더 빨리 사라지는 것  
본문: 시간이 지나도 가격은 다시 볼 수 있지만, 그때 왜 들어갔고 어디서 흔들렸는지는 금방 흐려집니다.

### 블록 2

제목: 기록이 없으면 복기는 왜곡되기 쉽습니다  
본문: 기록이 없으면 예전 판단을 복기하는 것이 아니라 나중의 감정으로 다시 해석하게 됩니다.

### 블록 3

제목: Kifu는 판단의 흔적을 남깁니다  
본문: 진입 이유, 정리 이유, 복기 메모를 거래와 함께 남겨 비슷한 장이 다시 왔을 때 내 기준부터 확인할 수 있게 합니다.

## 톤 가이드

- 과장 금지
- 수익 약속 금지
- 매매 신호처럼 읽히는 표현 금지
- 생산성 앱 톤보다 트레이더의 실제 문제를 먼저 말할 것
- `기록`, `복기`, `판단 이유`, `기준` 같은 단어를 우선 사용

## 제품 스레드와 나중에 연결할 지점

- Hero 문구가 실제 홈 카피와 어떻게 연결될지
- 어떤 화면을 proof로 쓸지
- CTA가 실제 진입 흐름과 맞는지
- `판단 이유`, `복기 메모`, `정리 이유`를 제품 언어로 어디까지 통일할지
